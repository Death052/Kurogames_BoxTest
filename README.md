# 📦 Box Push Game

A simple, lightweight puzzle game inspired by the classic **Sokoban**, featuring 3 unique levels and a built-in level editor!

---

## 🎮 Features

* **3 Mind-Bending Levels:** Test your logic and puzzle-solving skills.
* **Color-Matching Mechanics:** Match colored boxes to their corresponding pressure plates.
* **Built-in Level Editor:** Create and test your own custom puzzles easily.
* **Intuitive Controls:** Smooth movement and interaction mechanics.

---

## ⌨️ Controls

| Key | Action |
| :--- | :--- |
| **Arrow Keys** | Move player (Up, Down, Left, Right) |
| **Z Key** | Select/Interact with a box to push it in a direction |
| **Z Key (again)** | Deselect the currently held box |

---

## 🎯 Game Rules

1. **Push the Boxes:** Navigate the grid and maneuver the colored boxes.
2. **Match the Colors:** Push each colored box onto the pressure plate of the **same color**.
3. **Activate the Goal:** Once all colored boxes are correctly placed on their matching pressure plates, the goal will activate.
4. **Win the Level:** Walk your player into the activated goal to complete the level!




# 📦 推箱子小游戏 (Box Push Game)

一款受经典《推箱子》启发而创作的简单轻量级解谜游戏，包含 3 个独特的关卡以及一个内置关卡编辑器！

---

## 🎮 游戏特性

* **3 个烧脑关卡：** 考验你的逻辑和解谜能力。
* **颜色匹配机制：** 将彩色箱子推到对应的同色压力板上。
* **内置关卡编辑器：** 轻松设计、测试你自己的自定义谜题。
* **直观的控制：** 流畅的移动和交互机制。

---

## ⌨️ 操作控制

| 按键 | 动作 |
| :--- | :--- |
| **方向键 (Arrow Keys)** | 移动玩家（上、下、左、右） |
| **Z 键** | 选择/与箱子交互以将其向一个方向推动 |
| **再次按下 Z 键** | 取消选择当前持有的箱子 |

---

## 🎯 游戏规则

1. **推动箱子：** 在网格中导航并操纵彩色箱子。
2. **匹配颜色：** 将每个彩色箱子推到**相同颜色**的压力板上。
3. **激活终点：** 一旦所有彩色箱子都正确放置在相匹配的压力板上，终点将被激活。
4. **赢得关卡：** 走到被激活的终点处即可完成关卡！
